# 🎬 Movie Sales Analysis Using Power BI

## 📌 Project Overview

The **Movie Sales Analysis** project is an interactive Power BI dashboard designed to analyze movie performance, box office revenue, genre popularity, ratings, and sales trends.

The project transforms movie-related data into meaningful visual insights to understand which movies and genres perform well, identify trends over time, and explore the factors associated with movie success.

Using interactive visualizations and analytical measures, this project demonstrates how business intelligence can support data-driven decisions in the entertainment industry.

---

## 🎯 Business Problem

The entertainment industry generates large amounts of data related to movie releases, genres, ratings, and box office performance. However, analyzing this information effectively can be challenging when the data is scattered across records and reports.

Without a structured analytical approach, it may be difficult to identify successful movie genres, understand changes in performance over time, compare top-performing movies, and examine relationships between ratings and revenue.

This project uses Power BI to organize and analyze movie data, helping users explore performance patterns and make informed decisions based on the available information.

---

## 🎯 Project Objectives

* Analyze overall movie sales and box office performance.
* Identify trends in movie performance over time.
* Compare the performance of different movie genres.
* Examine movie ratings and their distribution.
* Identify top-performing movies based on available metrics.
* Explore relationships between ratings, revenue, and other available variables.
* Build an interactive dashboard for exploring movie performance.
* Present findings through clear and meaningful visualizations.
